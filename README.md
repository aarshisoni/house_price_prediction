# 🏠 House Price Prediction System

> A beginner-friendly Machine Learning project that predicts house prices based on
> property features, built with Python, Scikit-learn, and Streamlit.

---

## ⚠️ Dataset Disclaimer

**This project uses a fully synthetic (artificially generated) dataset.**
The data was created programmatically using `generate_dataset.py` with a fixed random seed.
It does **NOT** represent real housing-market data, real property listings, or any real-world prices.
It is intended purely for **educational and demo purposes**.

---

## 1. Project Overview

The House Price Prediction System is a complete, end-to-end machine learning project that:

- Generates a realistic synthetic housing dataset
- Trains multiple regression models
- Compares model performance using standard metrics
- Serves predictions through an interactive Streamlit web application

---

## 2. Objective

Build a supervised regression model that can estimate the price of a house given its features
such as area, number of bedrooms/bathrooms, stories, parking, age, and location.

---

## 3. Features

| Feature      | Type        | Description                                |
|--------------|-------------|--------------------------------------------|
| `area_sqft`  | Numerical   | Total floor area in square feet            |
| `bedrooms`   | Numerical   | Number of bedrooms                         |
| `bathrooms`  | Numerical   | Number of bathrooms                        |
| `stories`    | Numerical   | Number of floors/stories                   |
| `parking`    | Numerical   | Number of parking spots                    |
| `age_years`  | Numerical   | Age of the house in years                  |
| `location`   | Categorical | Location category of the house             |
| **`price`**  | **Target**  | **House price in Indian Rupees (₹)**       |

### Location Categories

- `City_Center` — Highest price premium (×1.35)
- `Downtown`    — High price premium (×1.20)
- `Suburban`    — Baseline (×1.00)
- `Rural`       — Lower price (×0.75)

## 5. Dataset Description

- **Records:** ~150 synthetic house records
- **Features:** 7 input features + 1 target (`price`)
- **Generated by:** `generate_dataset.py` with `random_seed=42`
- **Price range:** Approximately ₹5,00,000 – ₹50,00,000

### Price Generation Formula

```
raw_price = (area_sqft × 1200) + (bedrooms × 80,000)
          + (bathrooms × 60,000) + (stories × 40,000)
          + (parking × 30,000) − (age_years × 15,000)

price = raw_price × location_multiplier × noise_factor
```

---

## 6. Machine Learning Workflow

```
Generate Dataset  →  Load & Analyse  →  Split (80/20)
       ↓
Preprocess (StandardScaler + OneHotEncoder)
       ↓
Train 3 Models  →  Evaluate (MAE, RMSE, R²)  →  Select Best
       ↓
Save Pipeline (model/house_price_model.pkl)
       ↓
Streamlit App  →  Load Model  →  Predict
```

---

## 7. Models Used

1. **Linear Regression** — Baseline model, assumes linear relationship
2. **Decision Tree Regressor** — Non-linear, interpretable tree structure
3. **Random Forest Regressor** — Ensemble of 100 trees, typically best performance

---

## 8. Evaluation Metrics

| Metric | Full Name                     | Better when |
|--------|-------------------------------|-------------|
| MAE    | Mean Absolute Error           | Lower ↓     |
| RMSE   | Root Mean Squared Error       | Lower ↓     |
| R²     | Coefficient of Determination  | Higher ↑    |

The model with the highest R² score on the test set is automatically selected and saved.

## 15. Limitations

- The dataset is **synthetic** — predictions do not reflect real market prices
- The dataset is small (~150 records) — real-world models need thousands of records
- No external factors (economy, inflation, market trends) are modelled
- Location categories are simplified (only 4 options)
